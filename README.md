# Projeto - Algoritmos de Ordenação

Projeto desenvolvido em C++ para a Faculdade UNIP.

O programa realiza a leitura de dados de imagens e permite ordenar os registros utilizando:

- Bubble Sort
- Insertion Sort
- Quick Sort

## Critérios de ordenação

Os dados podem ser ordenados por:

- ID
- Nome
- Tamanho
- Largura
- Altura

## Funcionalidades

- Leitura de arquivo interno
- Leitura de arquivo externo
- Seleção de dados aleatórios
- Escolha da quantidade de registros
- Escolha do algoritmo
- Comparação de desempenho
- Interface simples utilizando Win32

## Estrutura do projeto

src/
├── algoritmos/
├── dados/
├── data/
├── desempenho/
├── interface/

## Tecnologias

- C++
- Win32 API
- Visual Studio Code
- Git e GitHub

## Objetivo

Comparar o funcionamento e o desempenho dos algoritmos Bubble Sort, Insertion Sort e Quick Sort utilizando diferentes quantidades de dados.
